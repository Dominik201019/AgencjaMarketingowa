# SYGNAŁ — Studio marketingu

Koncepcyjna strona agencji marketingowej do portfolio Dominika Druciarka. Pokazuje firmę, podejście, obszary współpracy i demonstracyjne projekty. Marka, dane oraz koncepcje LUMA, KROK i FORMA są fikcyjne.

## Gotowe pliki i publikacja

Cała strona jest w `dist`: `index.html`, `styles.css`, `script.js`, `favicon.svg`, `.nojekyll`, `mini-brief.txt` i folder `images`. Bez frameworka, instalacji i kompilacji. W paczce ZIP gotowe pliki znajdują się bezpośrednio w katalogu głównym.

GitHub Pages: rozpakuj ZIP i wgraj całą zawartość do nowego repozytorium. Zachowaj folder `images`. Settings → Pages → Deploy from a branch → main → /(root). Ścieżki względne obsługują również `/nazwa-repozytorium/`.

Podgląd lokalny: `node preview.cjs` i http://127.0.0.1:8781 lub otwarcie `dist/index.html`.

## Interakcje

- Menu mobilne, animacje wejścia, kompozycje kreatywne i ciągły pasek tekstowy. Systemowe ograniczenie ruchu wyłącza efekty.
- Rozwijane opisy kompetencji z wyborem tematu kontaktu.
- Trzy koncepcje projektowe z opisami wyzwania, kierunku i zakresu w oknie dialogowym.
- Mini brief do pobrania, FAQ oraz informacje o prywatności.
- Formularz z walidacją i lokalnym potwierdzeniem. Nie wysyła wiadomości ani nie rozpoczyna rzeczywistej współpracy.

Treści: `dist/index.html`, wygląd: `dist/styles.css`, działanie i dane projektów: `dist/script.js`. Kompozycje LUMA / KROK / FORMA wykonane w HTML i CSS. Zdjęcie stockowe Unsplash photo-1522071820081-009f0129c71c ilustruje współpracę, nie przedstawia rzeczywistego zespołu SYGNAŁ. Fonty Google Fonts: Unbounded i DM Sans.

Przed wykorzystaniem przez prawdziwą firmę należy uzupełnić rzeczywiste dane, zakres, informacje prawne i usługę obsługi formularza. Strona nie zawiera wymyślonych referencji ani wyników kampanii.
